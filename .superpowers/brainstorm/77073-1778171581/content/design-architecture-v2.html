Two Open Technical Questions (must resolve before build)

1. Consonant MCP Bridge — HTTP transport

The extension can't call MCP via stdio. We need to verify whether the consonant-specs MCP server exposes an HTTP/SSE endpoint, or whether we need to add a small HTTP wrapper. This must be confirmed before the Figma tool is implemented.

2. Strict-CSP site fallback

If a site's CSP can't be stripped (inline meta tags, HSTS pinning), the iframe will fail. The fallback: show an error card with a "Use Side Panel mode" button — opens the URL in a real tab and activates the extension's side panel instead. Adds ~2 days of scope.
