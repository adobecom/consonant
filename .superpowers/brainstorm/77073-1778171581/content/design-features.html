Left Rail — 7 Extraction Modes

Each button collects the full DOM + CSS + JS from the webview, then sends it to Claude Opus 4.7 with a specialized system prompt. Results stream into the right rail.

🎨 Design System
Extracts: color palette, typography scale, spacing scale, elevation, border radius, icon set. Returns structured JSON + human-readable summary.
🗺 DS Mapping
Maps the page's classes/tokens to known design systems (S2A, Material, Spectrum, etc.). Identifies custom vs. borrowed patterns. Shows confidence score per match.
✏️ Design Style
Infers visual language: tone (minimal, expressive, corporate), aesthetic patterns, brand personality signals from typography, color usage, and layout density.
📐 Design Principles
Infers design principles from UI patterns: hierarchy strategy, interaction model, information density philosophy. Named and explained, not just listed.
🎬 Animation
Extracts all CSS transitions, @keyframes, animation libraries (Framer, GSAP, etc.), timing functions, durations. Returns engineering-ready spec table.
🌍 Localization
Finds all hardcoded strings vs. i18n keys, detects locale-specific patterns (date formats, RTL support, currency), flags untranslated content.
♿ A11y
Runs full accessibility audit: ARIA roles + labels, color contrast (WCAG AA/AAA), keyboard navigation, focus order, missing alt text, form labels. Returns issues + suggestions with WCAG SC references.

Claude's Tool Palette — What Claude Can Call

Claude Opus 4.7 calls these tools automatically based on what the user asks. The background service worker executes them.

read_page() Returns full DOM HTML, all stylesheets, detected JS libraries, and page metadata from the webview. read_page_scripts() Returns all JS source (inline + linked). Used for animation library detection and logic analysis. preview_in_tab(html) Opens a new Chrome tab with the provided HTML as a Blob URL. Returns the tab ID for comparison. save_files(files[]) Saves one or more files to the user's designated folder via chrome.downloads. Auto-opens an index.html if present. push_to_figma(payload) POSTs a structured spec payload to the Consonant MCP bridge on localhost. Requires Consonant plugin open in Figma. navigate(url) Navigates the webview to a new URL. Used when Claude needs to follow links or check multiple pages. screenshot() Captures a screenshot of the current webview. Used for visual context in chat responses.
