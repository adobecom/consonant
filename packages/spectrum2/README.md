# packages/spectrum2 — contracts for Spectrum 2 components

Not our components. Contracts that describe Adobe's, so adobe.com can compose
on top of them and a reskin has something to aim at.

Evidence is read, never authored:
- code: the published `@spectrum-css/<component>` package (index.css + dist/metadata.json)
- design: the `S2 / Web` Figma library
- tokens: `@spectrum-css/tokens`, two tiers — the component's own CSS, then the global token build

Proof of concept only. Built by hand through the repo's own pipeline; nothing
here is wired into the gate yet.
