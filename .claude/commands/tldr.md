# TL;DR

Recap this conversation so far as a priority-ordered digest. No preamble, no narrative — the reader has not followed the thread and needs to act.

## Format

```
TL;DR — <date>

Decide (needs you)
1. …
2. …

Done (verified)
- …

Broken / open
- …

Next
- …
```

## Rules

- **Decide** comes first: anything blocked on the user's call, each with the one-line recommendation.
- **Done** lists only what was verified (a test, a run, a screenshot), with the number that proves it where one exists ("10/10 cells, focus 0.5%"). Not what was attempted.
- **Broken / open** names the thing and the cause if known; no excuses, no history.
- **Next** is what the assistant would do next if told "go", in order.
- At most 12 lines across all four sections. One line each. No sub-bullets, no code blocks, no links to files unless the file is the deliverable.
- If `$ARGUMENTS` names a topic, scope the digest to it.
- Keep names exact (component slugs, commands, file paths) so each line can be acted on.
