What changed and why
  • One button instead of two — "Start A11y Review" replaces "Generate Blueline" + "Generate Blueline Panels" — designers pick a mode elsewhere if needed
  • Plain language labels with descriptions — "Focus Styles" not "Focus Indicators (AI)" · "Keyboard Behavior" not "ARIA & Keyboard" · "Page Regions" not "Landmarks & Navigation"
  • Smart defaults pre-checked — most relevant checks selected on load, designer unchecks what doesn't apply
  • Confirmation screen before canvas changes — designer sees exactly what will be created before Figma is touched
  • Results summary back in the plugin — issues, items needing designer input, and suggestions appear inside the plugin after Claude Code runs
  • Advanced options hidden by default — Forms, Carousel, Motion, React Native, TV Note behind a toggle — not visible unless needed
  • Bridge explained, not just badged — "Claude Code connected" pill replaces the cryptic "connect bridge" badge
