Where should Claude's conversation live?

The biggest gap found: Purpose 5 (conversational) is entirely absent. Before we design anything else, we need to decide the core interaction model.

A

Chat-first — conversation inside the plugin

Replace the checkbox form with a chat panel inside the A11y tab. Designer describes what they want or picks a category; Claude asks questions, runs analysis, reports findings — all within the plugin. The terminal/Claude Code is only used for heavy lifting behind the scenes (invisible to designer).

Pros

  • Fully meets Purpose 5 (conversational)
  • Designer never leaves the plugin
  • No Claude Code knowledge required

Cons

  • Biggest rebuild — new UI surface
  • Requires streaming responses from bridge
B

Guided wizard — plugin drives, Claude Code assists

Keep the checkbox + generate model but add: (1) inline category descriptions, (2) a step-by-step guided flow with confirmation before any Figma canvas changes, (3) a findings summary panel inside the plugin after analysis runs, (4) Claude Code handles analysis but results are surfaced back into the plugin, not just into Figma cards.

Pros

  • Moderate rebuild
  • Meets Purposes 1, 2, 4, 6
  • Findings visible inside plugin

Cons

  • Still not fully conversational (Purpose 5 partial)
  • Claude Code still required but better explained
C

Fix + phase — fix UX now, add conversation later

Phase 1: Fix the immediate blockers (relabel categories, explain bridge, disambiguate buttons, add pre-commit confirmation, add findings summary). Phase 2: Add conversational layer as a separate feature. Ship something useful now, iterate toward the full vision.

Pros

  • Fastest to ship
  • Low risk, incremental
  • Fixes the most painful designer issues now

Cons

  • Purpose 5 still unmet in Phase 1
  • Two-phase plan means deferring the core vision

My recommendation: B (Guided wizard) — it closes 5 of 6 purposes without requiring a full rebuild, ships sooner than A, and is far more purpose-aligned than C. But A is the right long-term target.
