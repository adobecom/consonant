When Claude makes a change — how should it deliver it?

Both options are technically doable. Pick one, or both.

A

Preview tab (temporary)

Claude opens a new Chrome tab with the modified page. No files saved. Great for quick "what would this look like" exploration. You can go back and forth between the original and the preview tab.

Pros

  • Instant, no setup
  • Easy compare (tab switching)

Cons

  • Lost on close
  • Not a real codebase
B

Save to folder (persistent)

Claude writes modified HTML/CSS/JS files to a folder you designate. Opens in a new tab automatically so you can still compare. Files are real — you can open them in VS Code, commit them, etc.

Pros

  • Keeps the work
  • Real files you can edit

Cons

  • Requires picking a save folder on first use

You can select both — the tool would offer "Preview" and "Save" as two buttons after every Claude change.
