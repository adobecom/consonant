Where to focus now
Done (UI)
The plugin UI redesign addresses Purposes 4 and 6 fully. Purposes 2 and 3 are solid. This is ready to build.
Priority 1
Redesign the generated prompt. The command the plugin sends to Claude Code must change from a batch instruction to a conversation opener:

Today: "Fill ONLY these blueline categories for [frame]…"
Needed: "Start an A11y review conversation for [frame]. Use the structural scan. Ask the designer questions before filling any cards. Flag items where you're uncertain and leave them blank with a note explaining what you need. Separate your output into: issues found, suggestions, and items needing designer input."
Priority 2
Bridge results loop-back. After Claude Code runs, send a summary message back to the plugin via bridge so State 3 (issues/suggestions/needs-input panel) appears automatically. This is new bridge messaging — doesn't exist yet.
Priority 3
Smart category detection. Before committing cards, Claude should check whether each selected category actually applies to the frame (e.g., skip "Carousel" if no carousel exists). Prevents empty or irrelevant cards.
