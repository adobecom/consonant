Key Data Flow — "Turn this into dark mode"

1. User types: "Turn this into dark mode" in right rail
2. Background: Sends message to <webview> content script → returns full DOM + CSS
3. Claude API: Receives page context + user message, streams response
4. Claude calls tool: preview_in_tab({ html: "..." }) with modified HTML
5. Tool executor: Creates Blob URL, opens new tab
6. Chat UI: Shows "Opened in new tab — [compare ↗]" card + "Save files?" button
7. If user clicks Save: save_files() writes to designated folder via chrome.downloads
